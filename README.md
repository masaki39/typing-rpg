# 呪文詠唱タイピングRPG

呪文をローマ字で「詠唱（タイピング）」して魔物と戦う、ブラウザ用タイピングRPGのプロトタイプです。
ビルド不要・依存ゼロの静的サイトです。

## 遊び方

1. `index.html` をブラウザで直接開く（GitHub Pages などに置いてもそのまま動きます）
2. 入力を **半角英数（IMEオフ）** にして `Space` でスタート
3. 画面下の手札（4枚）から好きな呪文をローマ字で打ち始める。打った文字に合う呪文だけが残り、打ち切ると発動
4. 4体の魔物を連続で倒せばクリア。HP が 0 になったら `Space` でその敵に再挑戦、`Esc` で最初から

| 操作 | キー |
| --- | --- |
| 詠唱 | ローマ字入力（`shi`/`si`、`chi`/`ti`、`nn`/`n'`、`kka`/`xtuka` などの揺れに対応） |
| 詠唱を破棄 | `Esc` / `Backspace` |
| 決定・次へ | `Space` / `Enter` |

### ルール

- **長さと威力**: ★の多い長い呪文ほど高威力（打鍵数に対して威力が逓増）。ただし詠唱中も敵の攻撃タイマーは進み、詠唱中に被弾すると「詠唱が乱れ」威力 ×0.8
- **属性相性**: 水 → 火 → 氷 → 雷 → 水（矢印の先に 2 倍）。同属性は半減。カードに弱点/耐性が表示されます
- **ミスタイプ**: 詠唱中のミス 1 回につき威力 -10%（下限 40%）。ミスでコンボもリセット
- **コンボ**: ノーミスで詠唱を続けるとコンボ 1 につき +5%（最大 +50%）
- **手札**: 短詠唱★・中詠唱★★・長詠唱★★★・自由枠（回復呪文あり）の 4 枠。使った枠は同じ種類の別呪文で補充
- 最終ボスは数回に 1 回、2 倍の強攻撃を放ちます（タイマーが赤くなったら注意）
- 画面右に KPM（1 分あたりの正打鍵数）・正確率・コンボを表示。ウィンドウからフォーカスが外れると一時停止

## 構成

```
index.html            画面
style.css             スタイル
js/romaji.js          ローマ字入力エンジン（複数綴り対応・入力済み/残りの表示）
js/battle.js          戦闘計算（威力・属性相性・ミス/乱れ/コンボ倍率）
js/data.js            呪文・敵・属性のデータ
js/sfx.js             WebAudio の簡易効果音
js/game.js            ゲーム進行・描画・キー入力
tests/*.test.mjs      node:test によるテスト
```

`romaji.js` / `battle.js` / `data.js` は DOM 非依存で、ブラウザではグローバル変数、Node では `require` で読み込めます（`file://` で開けるよう ES Modules は使っていません）。

呪文や敵を追加するときは `js/data.js` を編集してください。威力は呪文の標準ローマ字の打鍵数から自動計算されます。

## テスト

```sh
node --test      # または pnpm test
```

Node.js 20 以上。依存パッケージはありません。
